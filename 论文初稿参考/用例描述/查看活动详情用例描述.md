# 查看活动详情用例描述

| 字段 | 内容 |
|------|------|
| **用例名称** | 查看活动详情 |
| **用例描述** | 用户（游客或已登录用户）在活动列表中点击活动卡片，查看活动的完整信息，包括基本信息、路线详情、组织者信息、报名状态、装备要求等。 |
| **执行者** | 游客（未登录用户）、注册用户（已登录用户） |
| **前置条件** | 1. 活动状态为已发布(2)、进行中(3)或已结束(4)<br>2. 活动未被删除（deleted=0） |
| **后置条件** | 1. 活动浏览次数(view_count)+1<br>2. 若用户已登录，系统额外返回用户报名状态<br>3. 根据活动状态和用户身份展示对应的操作按钮 |
| **主流程描述** | 1. 用户在活动列表页面浏览活动<br>2. 用户点击某个活动卡片<br>3. 系统查询活动详情（基本信息、路线、组织者）<br>4. 系统判断活动是否存在且已发布<br>5. 系统更新活动浏览次数<br>6. 系统判断用户是否已登录<br>7. 若已登录，系统查询用户在该活动的报名状态<br>8. 系统组装详情数据返回前端<br>9. 前端展示活动详情页面<br>10. 用户浏览活动基本信息（标题、难度、时间、费用、状态）<br>11. 用户浏览路线信息（距离、海拔、预计用时、起终点）<br>12. 用户浏览组织者信息（昵称、头像、角色）<br>13. 用户浏览装备要求和体能要求<br>14. 用户根据活动状态和登录状态选择后续操作 |
| **分支流程描述** | **分支1：已登录用户查看报名状态**<br>- 在第7步，若用户已登录且已报名<br>- 系统返回报名状态（待审核/已通过/已驳回/候补）<br>- 前端显示"我的报名状态"标签<br>- 若报名已通过，显示"查看集合方案"按钮<br><br>**分支2：活动已结束，可查看评价**<br>- 在第9步，若活动状态=已结束(4)<br>- 前端展示"活动评价"标签页<br>- 用户可查看其他参与者的评价和评分<br>- 若用户已参与该活动，显示"发表评价"按钮<br><br>**分支3：活动进行中，已报名用户可签到**<br>- 在第9步，若活动状态=进行中(3)且用户报名已通过<br>- 前端显示"活动签到"按钮<br>- 用户可跳转至签到页面 |
| **异常流程描述** | **异常1：活动不存在**<br>- 在第4步，若活动ID不存在<br>- 系统提示"活动不存在"<br>- 跳转回活动列表页<br>- 用例结束<br><br>**异常2：活动未发布**<br>- 在第4步，若活动状态为草稿、待审核或已驳回<br>- 系统提示"该活动尚未发布"<br>- 跳转回活动列表页<br>- 用例结束<br><br>**异常3：活动已取消**<br>- 在第4步，若活动状态=已取消(5)<br>- 系统提示"该活动已取消"<br>- 显示活动基本信息（仅只读）<br>- 不显示任何操作按钮<br>- 用例结束 |

## 补充说明

### 页面可用操作（按活动状态和用户身份）

| 活动状态 | 游客 | 已登录未报名 | 已登录已报名 |
|---------|------|------------|------------|
| 已发布(2) | 无操作 | 立即报名 | 查看集合方案/取消报名 |
| 进行中(3) | 无操作 | 立即报名 | 活动签到/查看集合方案 |
| 已结束(4) | 查看评价 | 查看评价 | 查看评价/发表评价 |

### 关键业务规则
- 游客可查看所有已发布活动的详情
- 活动详情页展示路线完整信息（距离、海拔、预计用时）
- 组织者信息展示昵称、头像，可点击查看组织者主页
- 浏览次数每次访问+1（不区分是否登录）
