# 发布徒步活动用例描述

| 字段 | 内容 |
|------|------|
| **用例名称** | 发布徒步活动 |
| **用例描述** | 组织者创建徒步活动，填写活动基本信息、时间地点、报名设置、关联路线与签到点，提交审核后由管理员审批通过后发布。 |
| **执行者** | 组织者（创建活动）、管理员（审核活动） |
| **前置条件** | 1. 组织者已登录系统且角色为组织者或管理员<br>2. 系统中存在可关联的路线（或组织者可自定义路线）<br>3. 组织者具有创建活动的权限 |
| **后置条件** | 1. 活动以DRAFT状态保存到数据库<br>2. 提交审核后状态变为PENDING_AUDIT<br>3. 管理员审核通过后状态变为PUBLISHED，活动对用户可见<br>4. 审核驳回后状态变为REJECTED，组织者可修改重新提交 |
| **主流程描述** | 1. 组织者进入活动创建页面<br>2. 组织者填写活动基本信息（标题、难度等级、封面图片、活动描述）<br>3. 组织者设置活动时间与地点（活动日期、开始/结束时间、报名截止时间）<br>4. 组织者选择关联路线（从已有路线选择或自定义）<br>5. 系统根据路线自动加载签到检查点信息<br>6. 组织者配置报名设置（最大参与人数、活动费用、是否需要审核报名）<br>7. 组织者填写装备要求和体能要求<br>8. 组织者点击"保存草稿"<br>9. 系统校验必填字段和业务规则<br>10. 校验通过，系统保存活动草稿（状态=DRAFT）<br>11. 组织者确认信息无误，点击"提交审核"<br>12. 系统更新活动状态为PENDING_AUDIT<br>13. 系统通知管理员有新活动待审核<br>14. 管理员查看活动详情<br>15. 管理员点击"通过"按钮<br>16. 系统更新活动状态为PUBLISHED<br>17. 系统通知组织者活动发布成功 |
| **分支流程描述** | **分支1：管理员驳回活动**<br>- 在第15步，管理员认为活动不符合要求<br>- 管理员点击"驳回"按钮<br>- 管理员填写驳回原因（必填）<br>- 系统更新活动状态为REJECTED<br>- 系统通知组织者活动被驳回及原因<br>- 组织者收到通知后可修改活动信息<br>- 组织者重新提交审核，用例回到第12步<br><br>**分支2：组织者取消活动**<br>- 活动已发布（状态=PUBLISHED）<br>- 组织者点击"取消活动"按钮<br>- 系统更新活动状态为CANCELLED<br>- 系统通知已报名用户活动已取消<br>- 用例结束 |
| **异常流程描述** | **异常1：必填字段校验失败**<br>- 在第9步，若必填字段为空或格式不正确<br>- 系统提示具体字段错误信息（如"活动标题不能为空"）<br>- 组织者修改后重新提交<br>- 用例回到第8步<br><br>**异常2：路线不存在**<br>- 在第4步，若选择的路线上已被删除<br>- 系统提示"所选路线不存在，请重新选择"<br>- 组织者重新选择路线<br>- 用例回到第4步<br><br>**异常3：时间设置不合理**<br>- 在第3步，若活动时间早于当前时间<br>- 或报名截止时间晚于活动开始时间<br>- 系统提示"时间设置不合理，请检查活动时间和报名截止时间"<br>- 组织者修改时间设置<br>- 用例回到第3步<br><br>**异常4：权限不足**<br>- 在第1步，若用户角色不是组织者或管理员<br>- 系统提示"您没有创建活动的权限"<br>- 用例结束 |

## 补充说明

### 状态流转
```
DRAFT(0) → PENDING_AUDIT(1) → PUBLISHED(2) → IN_PROGRESS(3) → ENDED(4)
                                    ↓
                              CANCELLED(5)
                                    ↑
                              REJECTED(6)
```

### 关键业务规则
- 活动标题长度：2-100字符
- 最大参与人数：1-999人
- 活动费用：≥0
- 报名截止时间必须早于活动开始时间
- 只有组织者和管理员可以创建活动
- 只有管理员可以审核活动
