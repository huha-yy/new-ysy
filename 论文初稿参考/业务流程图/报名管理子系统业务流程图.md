# 报名管理子系统 — 业务流程图

## 参与角色（三泳道）

| 泳道 | 角色 |
|------|------|
| 左 | 用户 |
| 中 | 系统平台 |
| 右 | 组织者 |

## 流程步骤

```
┌──────────────┬──────────────────┬─────────────────┐
│     用户      │     系统平台      │     组织者       │
├──────────────┼──────────────────┼─────────────────┤
│   ● (开始)   │                  │                 │
│      ↓       │                  │                 │
│  填写报名信息 →  校验报名条件     │                 │
│ (紧急联系人/  │      ↓           │                 │
│  电话/备注)   │  ◇ 名额是否已满？ │                 │
│              │  ↓否       ↓是   │                 │
│              │ [PENDING] [WAITING]                 │
│              │  待审核    进入候补│                 │
│              │      ↓           │                 │
│              │  通知组织者  ────→  收到报名通知     │
│              │                  │      ↓          │
│              │                  │  查看报名详情    │
│              │                  │      ↓          │
│              │                  │  ◇ 是否通过？   │
│              │                  │  ↓是      ↓否   │
│              │   更新状态    ←───│─ 通过    驳回   │
│              │      ↓           │                 │
│              │  ◇ 审核结果？     │                 │
│              │  ↓通过    ↓驳回   │                 │
│              │ APPROVED REJECTED│                 │
│              │ (参与人数+1)      │                 │
│              │    ↓         ↓   │                 │
│  ←───────────│── 通知用户结果    │                 │
│      ↓       │                  │                 │
│  ◇ 是否取消？ │                  │                 │
│  ↓否    ↓是  │                  │                 │
│ ◉结束  取消报名→ 更新为CANCELLED │                 │
│              │ (若已通过则人数-1)│                 │
│              │      ↓           │                 │
│              │  通知组织者  ────→  收到取消通知     │
│              │                  │  ◉(结束)        │
└──────────────┴──────────────────┴─────────────────┘
```

## 状态流转

```
         ┌─ 名额未满 → PENDING(0) ─┐
提交报名 ─┤                         ├→ APPROVED(1) → CANCELLED(4)
         └─ 名额已满 → WAITING(3) ─┘        ↑
                          │                  │
                          └── 组织者审核通过 ──┘

         PENDING/WAITING → REJECTED(2)
         PENDING/APPROVED/WAITING → CANCELLED(4)（用户主动取消）
```

## 各节点说明

### 用户操作
1. **填写报名信息**：紧急联系人、联系电话、备注，勾选装备和健康确认
2. **收到审核结果**：通过/驳回通知
3. **取消报名**：待审核、已通过、候补状态均可取消

### 系统平台处理
1. **校验报名条件**：活动状态、报名截止时间、是否重复报名
2. **名额判定**：未满→待审核，已满→候补排队
3. **人数管理**：通过时+1，取消已通过报名时-1

### 组织者操作
1. **查看报名详情**：用户信息、紧急联系人、备注
2. **审核报名**：通过或驳回（驳回需填原因），支持批量通过
