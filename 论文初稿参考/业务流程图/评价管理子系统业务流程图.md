# 评价管理子系统 — 业务流程图

## 参与角色（两泳道）

| 泳道 | 角色 |
|------|------|
| 左 | 用户 |
| 右 | 系统平台 |

## 流程步骤

```
┌──────────────┬──────────────────────┐
│     用户      │       系统平台        │
├──────────────┼──────────────────────┤
│   ● (开始)   │                      │
│      ↓       │                      │
│  进入已结束   →   校验评价权限        │
│  活动详情页   │       ↓              │
│              │   ◇ 是否有权评价？    │
│              │  (已参与+未评价过)    │
│              │   ↓否       ↓是      │
│  ←───────────│  仅可查看   展示评价  │
│  查看他人评价 │  他人评价   表单      │
│  ◉(结束)     │              ↓       │
│              │   ←──────────┘       │
│  填写评价内容 │                      │
│ (四维评分/文字│                      │
│  /图片/匿名)  │                      │
│      ↓       │                      │
│  提交评价    →   保存评价记录        │
│              │   更新活动评分统计     │
│      ↓       │       ↓              │
│  ←───────────│── 返回评价列表        │
│              │                      │
│  ◇ 后续操作？ │                      │
│  ↓      ↓    │                      │
│ 修改   删除   │                      │
│ 评价   评价   │                      │
│  ↓      ↓    │                      │
│  →  更新/删除记录 ←                  │
│     重新计算统计                     │
│      ↓       │                      │
│  ◉(结束)     │                      │
└──────────────┴──────────────────────┘
```

## 各节点说明

### 用户操作
1. **进入活动详情页**：活动状态为已结束(4)时显示评价入口
2. **填写评价内容**：四维评分（整体/路线/组织/安全，1-5星）、文字评价、图片、是否匿名
3. **后续管理**：可修改或删除自己的评价

### 系统平台处理
1. **校验评价权限**：活动已结束 + 用户报名已通过 + 未评价过
2. **保存评价记录**：存储评分、内容、图片，匿名评价隐藏用户信息
3. **评分统计**：计算四维平均分和评分分布（1-5星各多少条）
