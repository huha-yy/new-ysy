# 查看活动详情 — 业务流程图

## 参与角色（两泳道）

| 泳道 | 角色 |
|------|------|
| 左 | 用户 |
| 右 | 系统平台 |

## 流程步骤

```
┌───────────────┬──────────────────────┐
│     用户       │       系统平台        │
├───────────────┼──────────────────────┤
│   ● (开始)    │                      │
│      ↓        │                      │
│  点击活动卡片  →   查询活动详情        │
│               │       ↓              │
│               │   ◇ 活动是否存在      │
│               │    且已发布？         │
│               │   ↓否       ↓是      │
│   ←───────────│  提示不存在  组装详情  │
│  返回活动列表  │          (活动信息    │
│   ◉(结束)     │          +路线+组织者 │
│               │          +报名状态)  │
│       ↓       │       ↓              │
│   ←───────────│── 返回详情页面        │
│               │                      │
│  浏览活动详情  │                      │
│       ↓       │                      │
│  ◇ 选择操作？  │                      │
│  ↓     ↓     ↓│                      │
│ 报名  查看   查看                     │
│ 活动  集合   评价                     │
│       方案                           │
│  ↓     ↓     ↓│                      │
│  ◉(结束)      │                      │
└───────────────┴──────────────────────┘
```

## 各节点说明

### 用户操作
1. **点击活动卡片**：从活动列表进入详情页，无需登录
2. **浏览活动详情**：查看基本信息、路线、组织者、装备/体能要求
3. **选择操作**：根据活动状态和登录状态，可报名、查看集合方案或评价

### 系统平台处理
1. **查询活动详情**：校验活动是否存在且为已发布/进行中/已结束状态
2. **组装详情数据**：整合活动信息、路线、组织者信息、当前用户报名状态
3. **返回详情页面**：根据用户角色和活动状态展示对应的操作按钮

### 页面可用操作（按活动状态）

| 活动状态 | 可报名 | 可查看集合方案 | 可评价 |
|---------|--------|-------------|--------|
| 已发布(2) | ✅ | ✅（需已报名） | ❌ |
| 进行中(3) | ✅ | ✅（需已报名） | ❌ |
| 已结束(4) | ❌ | ✅（需已报名） | ✅ |
