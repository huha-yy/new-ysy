# 活动管理子系统 — 业务流程图

## 参与角色（三泳道）

| 泳道 | 角色 |
|------|------|
| 左 | 组织者 |
| 中 | 系统平台 |
| 右 | 管理员 |

## 流程步骤

```
┌──────────────┬──────────────────┬─────────────────┐
│    组织者     │     系统平台      │     管理员       │
├──────────────┼──────────────────┼─────────────────┤
│   ● (开始)   │                  │                 │
│      ↓       │                  │                 │
│  填写活动信息 →  保存活动草稿     │                 │
│ (基本信息/时间│   [DRAFT]        │                 │
│ /报名/路线)   │                  │                 │
│      ↓       │                  │                 │
│  提交审核    →  更新状态          │                 │
│              │  [PENDING_AUDIT] │                 │
│              │      ↓           │                 │
│              │  通知管理员  ────→  审核活动详情     │
│              │                  │      ↓          │
│              │                  │  ◇ 是否通过？   │
│              │                  │  ↓是      ↓否   │
│              │   更新状态    ←───│─ 通过    驳回   │
│              │      ↓           │                 │
│              │  ◇ 审核结果？     │                 │
│              │  ↓通过    ↓驳回   │                 │
│              │ PUBLISHED REJECTED│                 │
│              │    ↓         ↓   │                 │
│  发布成功 ←──│────┘         └──→│                 │
│      ↓       │                  │  组织者收到驳回  │
│  ◇ 后续操作？ │                  │      ↓          │
│  ↓      ↓    │                  │  ◇ 是否重新提交？│
│ 开始   取消   │                  │  ↓是      ↓否   │
│ 活动   活动   │                  │ 修改重提交 放弃  │
│  ↓      ↓    │                  │ (回到提交审核)   │
│  →  更新状态  │                  │        ◉(结束)  │
│     IN_PROGRESS                 │                 │
│     或CANCELLED                 │                 │
│      ↓       │                  │                 │
│  ◉(结束)     │                  │                 │
└──────────────┴──────────────────┴─────────────────┘
```

## 状态流转

```
DRAFT(0) → PENDING_AUDIT(1) → PUBLISHED(2) → IN_PROGRESS(3) → ENDED(4)
  ↑                             │       │
  └── REJECTED(6) ←─────────────┘       → CANCELLED(5)
      (可修改重提交)
```

## 各节点说明

### 组织者操作
1. **填写活动信息**：标题、难度、时间地点、报名设置、关联路线与签到点
2. **提交审核**：将草稿或被驳回活动提交审核
3. **发布后操作**：可开始活动（→进行中）或取消活动（→已取消）

### 系统平台处理
1. **保存活动草稿**：校验并持久化，状态设为 DRAFT
2. **状态流转**：根据操作更新活动状态
3. **消息通知**：审核提交时通知管理员，审核完成后通知组织者

### 管理员操作
1. **审核活动详情**：查看活动完整信息
2. **通过或驳回**：通过则发布，驳回需填写原因
