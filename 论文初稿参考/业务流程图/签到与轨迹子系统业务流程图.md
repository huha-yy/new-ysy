# 签到与轨迹子系统 — 业务流程图

## 参与角色（三泳道）

| 泳道 | 角色 |
|------|------|
| 左 | 参与者（用户） |
| 中 | 系统平台 |
| 右 | 组织者 |

## 流程步骤

```
┌──────────────┬───────────────────┬─────────────────┐
│    参与者     │      系统平台      │     组织者       │
├──────────────┼───────────────────┼─────────────────┤
│   ● (开始)   │                   │                 │
│      ↓       │                   │                 │
│  到达签到点   →  验证GPS位置      │                 │
│  发起签到     │      ↓            │                 │
│              │  ◇ 距离≤有效半径？ │                 │
│              │  ↓否       ↓是    │                 │
│  ←───────────│ 提示超出范围 记录签到│                │
│  重新定位     │  (正常/迟到)      │                 │
│              │      ↓            │                 │
│  继续行进     →  上报GPS轨迹      │                 │
│              │      ↓            │                 │
│              │  保存轨迹记录      │                 │
│              │      ↓            │                 │
│              │  ◇ 偏离路线？      │                 │
│              │  ↓否       ↓是    │                 │
│              │  正常    创建偏离预警│                │
│              │            ↓      │                 │
│              │  通知组织者  ─────→  收到预警通知    │
│              │                   │      ↓          │
│              │      ↓            │  查看监控面板    │
│              │  [定时任务检测]    │  (签到进度/     │
│              │  每5分钟检查：     │   轨迹/预警)    │
│              │  · 超时未签到      │      ↓          │

│              │  ◇ 检测到异常？    │                 │

│  ◉(结束)     │                   │                 │
└──────────────┴───────────────────┴─────────────────┘
```

## 预警类型

| 类型 | 触发条件 | 级别 |
|------|---------|------|
| 路线偏离 | 距最近路点 > 200m | 警告 |
| 严重偏离 | 距最近路点 > 500m | 严重 |
| 超时未签到 | 超过预计到达时间30分钟未签到 | 警告 |
| 失联 | 超过30分钟未上报轨迹 | 严重 |

## 各节点说明

### 参与者操作
1. **到达签到点发起签到**：系统获取GPS位置，与签到点坐标比对
2. **继续行进**：前端持续上报GPS轨迹数据（坐标、海拔、速度）

### 系统平台处理
1. **验证GPS位置**：计算用户与签到点距离，判断是否在有效半径内
2. **保存轨迹记录**：批量存储GPS数据，同时触发偏离检测
3. **定时任务**：每5分钟自动检测超时未签到和失联用户

### 组织者操作
1. **查看监控面板**：实时查看所有参与者签到进度和位置
2. **处理预警**：收到预警通知后查看详情并采取措施
