# 系统业务功能类图

## 类图概述

本系统采用面向对象的设计思想，将业务实体抽象为类。系统包含三个核心子系统：活动管理、报名管理、签到与轨迹，主要业务类及其关系如下。

## 类职责说明

| 类名 | 职责 | 核心属性 | 核心操作 |
|------|------|---------|---------|
| **User** | 系统用户 | id, nickname, role | login(), createActivity(), registerActivity(), checkIn() |
| **Activity** | 徒步活动 | id, title, status, maxParticipants | submitForAudit(), publish(), start(), isFull() |
| **Route** | 徒步路线 | id, name, distance, difficulty | getPoints() |
| **RoutePoint** | 路线路点 | latitude, longitude, pointType | getNextPoint() |
| **Checkpoint** | 签到检查点 | name, latitude, longitude, radius | isInRange() |
| **Registration** | 报名记录 | userId, activityId, status, queueNumber | approve(), reject(), cancel() |
| **CheckInRecord** | 签到记录 | userId, checkpointId, checkInTime, status | validateLocation(), isLate() |
| **TrackRecord** | 轨迹记录 | userId, latitude, longitude, recordTime | batchCreate(), checkDeviation() |
| **AlertEvent** | 预警事件 | userId, alertType, alertLevel, status | resolve(), notifyOrganizer() |

## 类关系说明

| 关系 | 多重性 | 说明 |
|------|--------|------|
| User → Activity | 1 对 * | 一个组织者创建多个活动 |
| Activity → Route | * 对 1 | 多个活动使用同一条路线 |
| Route → RoutePoint | 1 对 * | 一条路线包含多个路点 |
| Activity → Checkpoint | 1 对 * | 一个活动有多个签到点 |
| User → Registration | 1 对 * | 一个用户多次报名 |
| User → CheckInRecord | 1 对 * | 一个用户多次签到 |
| User → TrackRecord | 1 对 * | 一个用户多条轨迹 |
| User → AlertEvent | 1 对 * | 一个用户多个预警 |
