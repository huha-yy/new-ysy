@startuml
skinparam sequenceMessageAlign center

title 活动管理-发布徒步活动时序图

participant "User" as User
participant "React" as React
participant "Controller" as Controller
participant "Service" as Service
participant "Mapper" as Mapper
participant "MySQL" as MySQL

User -> React: 1. 填写活动信息
activate React

React -> React: 2. 表单校验

React -> Controller: 3. POST /api/activities\n(携带JWT Token)
activate Controller

Controller -> Controller: 4. JWT认证\n@Valid参数校验

Controller -> Service: 5. createActivity(organizerId, createDTO)
activate Service

Service -> Mapper: 6. 校验用户角色\n(必须是组织者或管理员)
activate Mapper
Mapper -> MySQL: SELECT * FROM user\nWHERE id=?
activate MySQL
MySQL --> Mapper: 用户信息
deactivate MySQL
Mapper --> Service: 角色验证通过
deactivate Mapper

Service -> Mapper: 7. 校验路线是否存在
activate Mapper
Mapper -> MySQL: SELECT * FROM route\nWHERE id=?
activate MySQL
MySQL --> Mapper: 路线信息
deactivate MySQL
Mapper --> Service: 路线存在
deactivate Mapper

Service -> Service: 8. 构建Activity对象\n(status=0 草稿状态)

Service -> Mapper: 9. 插入活动记录
activate Mapper
Mapper -> MySQL: INSERT INTO activity
activate MySQL
MySQL --> Mapper: 返回活动ID
deactivate MySQL
Mapper --> Service: 活动ID
deactivate Mapper

Service --> Controller: 10. 返回活动ID
deactivate Service

Controller --> React: 11. 成功响应\n(code=200, activityId)
deactivate Controller

React --> User: 12. 显示"发布成功，等待审核"
deactivate React

@enduml
