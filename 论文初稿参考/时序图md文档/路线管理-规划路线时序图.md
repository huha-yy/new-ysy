@startuml
skinparam sequenceMessageAlign center

title 路线管理-规划路线时序图

participant "User" as User
participant "React" as React
participant "Controller" as Controller
participant "Service" as Service
participant "Mapper" as Mapper
participant "MySQL" as MySQL

User -> React: 1. 填写路线信息
activate React

React -> React: 2. 表单校验

React -> Controller: 3. POST /api/routes\n(携带JWT Token)
activate Controller

Controller -> Controller: 4. JWT认证\n@Valid参数校验

Controller -> Service: 5. createRoute(userId, createDTO)
activate Service

Service -> Mapper: 6. 校验用户是否存在
activate Mapper
Mapper -> MySQL: SELECT * FROM user\nWHERE id=?
activate MySQL
MySQL --> Mapper: 用户信息
deactivate MySQL
Mapper --> Service: 用户存在
deactivate Mapper

Service -> Service: 7. 构建Route对象\n(status=1 正常状态)

Service -> Mapper: 8. 插入路线记录
activate Mapper
Mapper -> MySQL: INSERT INTO route
activate MySQL
MySQL --> Mapper: 返回路线ID
deactivate MySQL
Mapper --> Service: 路线ID
deactivate Mapper

Service -> Mapper: 9. 插入路线点记录
activate Mapper
Mapper -> MySQL: INSERT INTO route_point\n(批量插入)
activate MySQL
MySQL --> Mapper: 插入成功
deactivate MySQL
Mapper --> Service: 插入成功
deactivate Mapper

Service -> Mapper: 10. 插入签到点记录
activate Mapper
Mapper -> MySQL: INSERT INTO checkpoint\n(批量插入)
activate MySQL
MySQL --> Mapper: 插入成功
deactivate MySQL
Mapper --> Service: 插入成功
deactivate Mapper

Service --> Controller: 11. 返回路线ID
deactivate Service

Controller --> React: 12. 成功响应\n(code=200, routeId)
deactivate Controller

React --> User: 13. 显示"路线创建成功"
deactivate React

@enduml
