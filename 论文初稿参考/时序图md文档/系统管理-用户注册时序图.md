@startuml
skinparam sequenceMessageAlign center

title 系统管理-用户注册时序图

participant "User" as User
participant "React" as React
participant "Controller" as Controller
participant "Service" as Service
participant "Mapper" as Mapper
participant "MySQL" as MySQL

User -> React: 1. 填写注册信息
activate React

React -> React: 2. 表单校验

React -> Controller: 3. POST /api/auth/register
activate Controller

Controller -> Controller: 4. @Valid参数校验

Controller -> Service: 5. register(userDTO)
activate Service

Service -> Mapper: 6. 校验用户名唯一性
activate Mapper
Mapper -> MySQL: SELECT * FROM user\nWHERE username=?
activate MySQL
MySQL --> Mapper: 查询结果
deactivate MySQL
Mapper --> Service: 用户名可用
deactivate Mapper

Service -> Mapper: 7. 校验手机号唯一性
activate Mapper
Mapper -> MySQL: SELECT * FROM user\nWHERE phone=?
activate MySQL
MySQL --> Mapper: 查询结果
deactivate MySQL
Mapper --> Service: 手机号可用
deactivate Mapper

Service -> Mapper: 8. 校验邮箱唯一性
activate Mapper
Mapper -> MySQL: SELECT * FROM user\nWHERE email=?
activate MySQL
MySQL --> Mapper: 查询结果
deactivate MySQL
Mapper --> Service: 邮箱可用
deactivate Mapper

Service -> Service: 9. 密码加密(BCrypt)

Service -> Mapper: 10. 插入用户记录
activate Mapper
Mapper -> MySQL: INSERT INTO user
activate MySQL
MySQL --> Mapper: 返回用户ID
deactivate MySQL
Mapper --> Service: 用户ID
deactivate Mapper

Service -> Mapper: 11. 创建用户档案
activate Mapper
Mapper -> MySQL: INSERT INTO user_profile
activate MySQL
MySQL --> Mapper: 创建成功
deactivate MySQL
Mapper --> Service: 成功
deactivate Mapper

Service -> Service: 12. 生成JWT Token

Service --> Controller: 13. 返回LoginVO
deactivate Service

Controller --> React: 14. 成功响应
deactivate Controller

React --> User: 15. 注册成功，跳转登录
deactivate React

@enduml
