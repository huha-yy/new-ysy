@startuml
skinparam sequenceMessageAlign center

title 报名管理-提交报名申请时序图

participant "User" as User
participant "React" as React
participant "Controller" as Controller
participant "Service" as Service
participant "Mapper" as Mapper
participant "MySQL" as MySQL

User -> React: 1. 点击"报名参加"
activate React

React -> React: 2. 填写报名信息

React -> Controller: 3. POST /api/registrations\n(携带JWT Token)
activate Controller

Controller -> Controller: 4. JWT认证\n@Valid参数校验

Controller -> Service: 5. submitRegistration(userId, createDTO)
activate Service

Service -> Mapper: 6. 校验用户是否存在
activate Mapper
Mapper -> MySQL: SELECT * FROM user\nWHERE id=?
activate MySQL
MySQL --> Mapper: 用户信息
deactivate MySQL
Mapper --> Service: 用户存在
deactivate Mapper

Service -> Mapper: 7. 校验活动状态\n(已发布或进行中)
activate Mapper
Mapper -> MySQL: SELECT * FROM activity\nWHERE id=?
activate MySQL
MySQL --> Mapper: 活动信息
deactivate MySQL
Mapper --> Service: 活动可报名
deactivate Mapper

Service -> Mapper: 8. 校验报名截止时间
activate Mapper
Mapper --> Service: 未超过截止时间
deactivate Mapper

Service -> Mapper: 9. 校验是否已报名
activate Mapper
Mapper -> MySQL: SELECT * FROM registration\nWHERE user_id=? AND activity_id=?
activate MySQL
MySQL --> Mapper: 查询结果
deactivate MySQL
Mapper --> Service: 未报名
deactivate Mapper

Service -> Mapper: 10. 校验活动容量
activate Mapper
Mapper --> Service: 返回当前人数和上限
deactivate Mapper

Service -> Service: 11. 判断是否已满\n未满:待审核\n已满:候补

Service -> Mapper: 12. 插入报名记录\n(status=0或3)
activate Mapper
Mapper -> MySQL: INSERT INTO registration
activate MySQL
MySQL --> Mapper: 返回报名ID
deactivate MySQL
Mapper --> Service: 报名ID
deactivate Mapper

Service --> Controller: 13. 返回报名ID
deactivate Service

Controller --> React: 14. 成功响应\n(code=200, registrationId)
deactivate Controller

React --> User: 15. "报名成功，等待审核"
deactivate React

@enduml
