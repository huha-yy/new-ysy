@startuml
skinparam sequenceMessageAlign center

title 评价反馈-发送活动评价时序图

participant "User" as User
participant "React" as React
participant "Controller" as Controller
participant "Service" as Service
participant "Mapper" as Mapper
participant "MySQL" as MySQL

User -> React: 1. 填写评价信息
activate React

React -> React: 2. 表单校验

React -> Controller: 3. POST /api/activities/{id}/reviews\n(携带JWT Token)
activate Controller

Controller -> Controller: 4. JWT认证\n@Valid参数校验

Controller -> Service: 5. submitReview
activate Service

Service -> Mapper: 6. 校验用户和活动状态
activate Mapper
Mapper -> MySQL: 查询用户、活动、报名记录
activate MySQL
MySQL --> Mapper: 活动已结束、用户已参与
deactivate MySQL
Mapper --> Service: 校验通过
deactivate Mapper

Service -> Mapper: 7. 校验是否已评价
activate Mapper
Mapper -> MySQL: SELECT * FROM review\nWHERE user_id=? AND activity_id=?
activate MySQL
MySQL --> Mapper: 查询结果
deactivate MySQL
Mapper --> Service: 未评价
deactivate Mapper

Service -> Service: 8. 构建Review对象\n(status=1 显示状态)

Service -> Mapper: 9. 插入评价记录
activate Mapper
Mapper -> MySQL: INSERT INTO review
activate MySQL
MySQL --> Mapper: 返回评价ID
deactivate MySQL
Mapper --> Service: 评价ID
deactivate Mapper

Service --> Controller: 10. 返回评价ID
deactivate Service

Controller --> React: 11. 成功响应\n(code=200, reviewId)
deactivate Controller

React --> User: 12. 显示"评价提交成功"
deactivate React

@enduml
