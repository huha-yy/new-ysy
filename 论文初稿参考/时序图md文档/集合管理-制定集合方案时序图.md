@startuml
skinparam sequenceMessageAlign center

title 集合管理-制定集合方案时序图

participant "User" as User
participant "React" as React
participant "Controller" as Controller
participant "Service" as Service
participant "Mapper" as Mapper
participant "MySQL" as MySQL

User -> React: 1. 填写集合方案信息
activate React

React -> React: 2. 表单校验

React -> Controller: 3. POST /api/activities/{id}/gathering\n(携带JWT Token)
activate Controller

Controller -> Controller: 4. JWT认证\n@Valid参数校验

Controller -> Service: 5. createGatheringPlan
activate Service

Service -> Mapper: 6. 校验活动是否存在
activate Mapper
Mapper -> MySQL: SELECT * FROM activity\nWHERE id=?
activate MySQL
MySQL --> Mapper: 活动信息
deactivate MySQL
Mapper --> Service: 活动存在
deactivate Mapper

Service -> Service: 7. 校验权限\n(必须是活动组织者)

Service -> Mapper: 8. 校验是否已存在集合方案
activate Mapper
Mapper -> MySQL: SELECT * FROM gathering_plan\nWHERE activity_id=?
activate MySQL
MySQL --> Mapper: 查询结果
deactivate MySQL
Mapper --> Service: 不存在集合方案
deactivate Mapper

Service -> Service: 9. 构建GatheringPlan对象\n(isPublished=0 未发布状态)

Service -> Mapper: 10. 插入集合方案记录
activate Mapper
Mapper -> MySQL: INSERT INTO gathering_plan
activate MySQL
MySQL --> Mapper: 返回方案ID
deactivate MySQL
Mapper --> Service: 方案ID
deactivate Mapper

Service --> Controller: 11. 返回方案ID
deactivate Service

Controller --> React: 12. 成功响应\n(code=200, planId)
deactivate Controller

React --> User: 13. 显示"集合方案创建成功"
deactivate React

@enduml
