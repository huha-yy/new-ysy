@startuml
skinparam sequenceMessageAlign center

title 消息通知-消息推送时序图

participant "System" as System
participant "Service" as Service
participant "Mapper" as Mapper
participant "MySQL" as MySQL
participant "React" as React
participant "User" as User

System -> Service: 1. 触发消息推送\n(报名通过/活动通知等)
activate Service

Service -> Service: 2. 构建消息内容

Service -> Mapper: 3. 插入消息记录
activate Mapper
Mapper -> MySQL: INSERT INTO message
activate MySQL
MySQL --> Mapper: 返回消息ID
deactivate MySQL
Mapper --> Service: 消息ID
deactivate Mapper

Service --> System: 4. 推送成功
deactivate Service

User -> React: 5. 进入消息页面
activate React

React -> Service: 6. GET /api/user/messages\n(携带JWT Token)
activate Service

Service -> Mapper: 7. 查询用户消息列表
activate Mapper
Mapper -> MySQL: SELECT * FROM message\nWHERE user_id=?
activate MySQL
MySQL --> Mapper: 消息列表
deactivate MySQL
Mapper --> Service: 消息数据
deactivate Mapper

Service --> React: 8. 返回消息列表
deactivate Service

React --> User: 9. 显示消息列表
deactivate React

@enduml
