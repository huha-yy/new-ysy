# 评价管理子系统 — 用例图

## 参与者（Actor）

| 参与者 | 说明 |
|--------|------|
| 游客 | 未登录用户，可查看活动评价 |
| 用户（User） | 已参与活动的用户，可发表和管理评价 |

## 用例清单

| 编号 | 用例名称 | 参与者 | 关系 | 说明 |
|------|---------|--------|------|------|
| UC-01 | 查看活动评价 | 游客、用户 | — | 查看活动的评价列表和评分统计 |
| UC-02 | 查看评分统计 | 游客、用户 | «include» ← UC-01 | 查看四维平均分和评分分布 |
| UC-03 | 发表评价 | 用户 | — | 提交四维评分、文字、图片 |
| UC-04 | 匿名评价 | 用户 | «extend» ← UC-03 | 选择匿名后隐藏用户信息 |
| UC-05 | 修改评价 | 用户 | — | 修改自己已发表的评价内容 |
| UC-06 | 删除评价 | 用户 | — | 删除自己已发表的评价 |

## 关键用例描述

### UC-03 发表评价

| 项目 | 内容 |
|------|------|
| 参与者 | 用户 |
| 前置条件 | 活动已结束(4)，用户报名已通过(1)，未评价过 |
| 后置条件 | 评价记录入库，活动评分统计更新 |
| 基本流程 | 1. 用户进入已结束活动详情 → 2. 填写四维评分（整体/路线/组织/安全） → 3. 填写文字评价，可上传图片 → 4. 可选匿名 → 5. 提交，系统保存并更新统计 |
| 异常流程 | 1a. 用户未参与该活动，不显示评价入口 |

### UC-01 查看活动评价

| 项目 | 内容 |
|------|------|
| 参与者 | 游客、用户 |
| 前置条件 | 活动已结束 |
| 后置条件 | 无 |
| 基本流程 | 1. 进入活动详情评价标签页 → 2. 查看四维平均分和评分分布 → 3. 浏览评价列表（匿名评价显示为"匿名用户"） |
