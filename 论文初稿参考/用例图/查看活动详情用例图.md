# 查看活动详情 — 用例图

## 参与者（Actor）

| 参与者 | 说明 |
|--------|------|
| 游客（Visitor） | 未登录用户，可浏览活动详情 |
| 注册用户（User） | 已登录用户，可报名和评价 |
| 组织者（Organizer） | 活动创建者，可管理集合方案 |

## 用例清单

| 编号 | 用例名称 | 参与者 | 关系 | 说明 |
|------|---------|--------|------|------|
| UC-01 | 查看活动详情 | 游客、注册用户、组织者 | — | 查看活动基本信息、路线、组织者、要求等 |
| UC-02 | 查看路线信息 | 游客、注册用户、组织者 | «include» ← UC-01 | 展示关联路线的距离、海拔、预计用时等 |
| UC-03 | 查看组织者信息 | 游客、注册用户、组织者 | «include» ← UC-01 | 展示组织者昵称、头像 |
| UC-04 | 报名活动 | 注册用户 | «extend» ← UC-01 | 活动已发布/进行中时，填写紧急联系人提交报名 |
| UC-05 | 查看集合方案 | 注册用户、组织者 | «extend» ← UC-01 | 已报名用户查看集合时间地点等信息 |
| UC-06 | 查看活动评价 | 游客、注册用户、组织者 | «extend» ← UC-01 | 活动已结束时，查看其他用户的评分和评价 |
| UC-07 | 发表评价 | 注册用户 | «extend» ← UC-06 | 活动已结束且已参与时，提交评分和评价内容 |

## 关键用例描述

### UC-01 查看活动详情

| 项目 | 内容 |
|------|------|
| 用例名称 | 查看活动详情 |
| 参与者 | 游客、注册用户、组织者 |
| 前置条件 | 活动状态为已发布(2)、进行中(3)或已结束(4) |
| 后置条件 | 活动浏览次数 +1 |
| 基本流程 | 1. 用户在活动列表点击活动卡片 |
|          | 2. 系统查询活动详情（基本信息、路线、组织者） |
|          | 3. 若用户已登录，系统额外查询报名状态 |
|          | 4. 系统返回详情页面，展示活动完整信息 |
|          | 5. 根据活动状态和用户身份展示可用操作按钮 |
| 异常流程 | 2a. 活动不存在或未发布，提示错误并返回列表 |

### UC-04 报名活动

| 项目 | 内容 |
|------|------|
| 用例名称 | 报名活动 |
| 参与者 | 注册用户 |
| 前置条件 | 用户已登录，活动状态为已发布(2)或进行中(3)，名额未满 |
| 后置条件 | 生成报名记录，状态为待审核(0) |
| 基本流程 | 1. 用户点击"立即报名"按钮 |
|          | 2. 弹出报名表单（紧急联系人、联系电话、备注） |
|          | 3. 用户勾选装备确认和健康确认 |
|          | 4. 提交报名，系统创建待审核报名记录 |
|          | 5. 跳转至"我的报名"页面 |
| 异常流程 | 4a. 名额已满，提示报名失败 |
