# 签到与轨迹子系统 — 用例图

## 参与者（Actor）

| 参与者 | 说明 |
|--------|------|
| 参与者（User） | 已报名通过的活动参与者 |
| 组织者（Organizer） | 活动创建者，监控签到和轨迹 |
| 定时任务（System） | 系统自动执行的预警检测任务 |

## 用例清单

| 编号 | 用例名称 | 参与者 | 关系 | 说明 |
|------|---------|--------|------|------|
| UC-01 | GPS签到 | 参与者 | — | 到达签到点后提交GPS位置完成签到 |
| UC-02 | 验证签到位置 | 参与者 | «include» ← UC-01 | 计算与签到点距离，判断是否在有效范围 |
| UC-03 | 上报GPS轨迹 | 参与者 | — | 行进中持续上报位置、海拔、速度 |
| UC-04 | 检测路线偏离 | 定时任务 | «include» ← UC-03 | 轨迹上报时自动检测是否偏离路线 |
| UC-05 | 检测超时未签到 | 定时任务 | — | 每5分钟检查是否有参与者超时未签到 |
| UC-06 | 检测失联用户 | 定时任务 | — | 每5分钟检查是否有参与者超过30分钟未上报轨迹 |
| UC-07 | 查看签到监控 | 组织者 | — | 查看所有参与者签到进度和位置 |
| UC-08 | 处理预警 | 组织者 | — | 查看和处理各类预警事件 |

## 关键用例描述

### UC-01 GPS签到

| 项目 | 内容 |
|------|------|
| 参与者 | 参与者 |
| 前置条件 | 用户报名已通过，活动进行中，未在该签到点签过到 |
| 后置条件 | 生成签到记录（正常/迟到） |
| 基本流程 | 1. 参与者到达签到点 → 2. 点击签到，系统获取GPS坐标 → 3. 计算与签到点距离 → 4. 距离≤有效半径，签到成功 |
| 异常流程 | 4a. 距离超出范围，提示重新定位 |

### UC-07 查看签到监控

| 项目 | 内容 |
|------|------|
| 参与者 | 组织者 |
| 前置条件 | 活动进行中，当前用户为活动组织者 |
| 后置条件 | 无 |
| 基本流程 | 1. 组织者进入监控页面 → 2. 查看各签到点统计（已签/未签人数） → 3. 查看每位参与者签到进度和最后位置 → 4. 查看预警标记（超时/失联） |
