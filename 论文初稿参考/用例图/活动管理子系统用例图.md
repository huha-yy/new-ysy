# 活动管理子系统 — 用例图

## 参与者（Actor）

| 参与者 | 说明 |
|--------|------|
| 游客 | 未登录用户，可浏览已发布活动 |
| 组织者 | 创建和管理活动，角色值 = 1 |
| 管理员 | 审核活动，角色值 = 2 |

## 用例清单

| 编号 | 用例名称 | 参与者 | 关系 | 说明 |
|------|---------|--------|------|------|
| UC-01 | 创建活动 | 组织者 | — | 填写信息保存为 DRAFT |
| UC-02 | 填写活动信息 | 组织者 | «include» ← UC-01 | 标题、难度、时间、报名配置 |
| UC-03 | 选择关联路线 | 组织者 | «include» ← UC-01 | 关联路线并配置签到检查点 |
| UC-04 | 提交审核 | 组织者 | — | DRAFT/REJECTED → PENDING_AUDIT |
| UC-05 | 审核活动 | 管理员 | — | 查看详情并做出审批决定 |
| UC-06 | 通过发布 | 管理员 | «extend» ← UC-05 | 状态 → PUBLISHED |
| UC-07 | 驳回活动 | 管理员 | «extend» ← UC-05 | 填写原因，状态 → REJECTED |
| UC-08 | 查看活动详情 | 游客、组织者、管理员 | — | 查看已发布活动的完整信息 |
| UC-09 | 开始活动 | 组织者 | — | PUBLISHED → IN_PROGRESS |
| UC-10 | 取消活动 | 组织者 | — | PUBLISHED → CANCELLED |

## 关键用例描述

### UC-01 创建活动

| 项目 | 内容 |
|------|------|
| 参与者 | 组织者 |
| 前置条件 | 用户已登录且角色为组织者或管理员 |
| 后置条件 | 活动以 DRAFT(0) 状态保存 |
| 基本流程 | 1. 组织者进入创建页面 → 2. 填写基本信息、时间地点、报名设置 → 3. 选择关联路线与签到点 → 4. 系统校验并保存草稿 |
| 异常流程 | 4a. 校验失败，返回错误提示 |

### UC-05 审核活动

| 项目 | 内容 |
|------|------|
| 参与者 | 管理员 |
| 前置条件 | 活动状态为 PENDING_AUDIT(1) |
| 后置条件 | 状态变为 PUBLISHED(2) 或 REJECTED(6) |
| 基本流程 | 1. 管理员查看待审核列表 → 2. 查看活动详情 → 3. 通过或驳回（驳回需填原因） → 4. 系统更新状态并通知组织者 |
