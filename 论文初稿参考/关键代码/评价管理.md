# 评价管理 - 核心代码

```java
@Service
@Slf4j
@RequiredArgsConstructor
public class ReviewServiceImpl implements ReviewService {
    private final ReviewMapper reviewMapper;
    private final ActivityMapper activityMapper;
    private final RegistrationMapper registrationMapper;

    // 状态常量：报名已通过、活动已结束、评价显示
    private static final int REGISTRATION_STATUS_APPROVED = 1;
    private static final int ACTIVITY_STATUS_ENDED = 4;
    private static final int REVIEW_STATUS_VISIBLE = 1;

    /**
     * 提交活动评价（仅已完成活动的参与者可提交）
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public Long submitReview(Long userId, Long activityId, ReviewCreateDTO createDTO) {
        // 1. 校验活动是否存在且已结束
        Activity activity = activityMapper.selectById(activityId);
        if (activity == null || activity.getStatus() != ACTIVITY_STATUS_ENDED) {
            throw new BusinessException(ResultCode.ACTIVITY_NOT_ENDED);
        }

        // 2. 校验用户是否已完成该活动（报名状态为已通过）
        LambdaQueryWrapper<Registration> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(Registration::getUserId, userId)
               .eq(Registration::getActivityId, activityId)
               .eq(Registration::getStatus, REGISTRATION_STATUS_APPROVED);
        if (registrationMapper.selectOne(wrapper) == null) {
            throw new BusinessException(ResultCode.NOT_REGISTERED_FOR_ACTIVITY);
        }

        // 3. 校验是否已评价过（每人每活动仅可评价一次）
        LambdaQueryWrapper<Review> reviewWrapper = new LambdaQueryWrapper<>();
        reviewWrapper.eq(Review::getUserId, userId).eq(Review::getActivityId, activityId);
        if (reviewMapper.selectOne(reviewWrapper) != null) {
            throw new BusinessException(ResultCode.ALREADY_REVIEWED);
        }

        // 4. 构建评价对象（4个维度评分，等权重计算平均值）
        Review review = Review.builder()
                .userId(userId).activityId(activityId)
                .overallRating(createDTO.getOverallRating())
                .routeRating(createDTO.getRouteRating())
                .organizationRating(createDTO.getOrganizationRating())
                .safetyRating(createDTO.getSafetyRating())
                .content(createDTO.getContent())
                .images(createDTO.getImages())
                .isAnonymous(createDTO.getIsAnonymous() != null ? createDTO.getIsAnonymous() : 0)
                .status(REVIEW_STATUS_VISIBLE).build();

        reviewMapper.insert(review);
        log.info("评价提交成功，用户ID：{}，活动ID：{}", userId, activityId);
        return review.getId();
    }
}
```

## 评分机制说明

- **评分维度**：整体评分、路线评分、组织评分、安全评分（各1-5星）
- **权重分配**：等权重，每个维度占25%
- **计算公式**：averageRating = (整体 + 路线 + 组织 + 安全) / 4
- **评价限制**：每人每活动仅可评价一次，仅已通过报名且活动已结束的用户可评价
