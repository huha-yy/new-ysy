# 用户管理 - 核心代码

```java
@Service
@Slf4j
@RequiredArgsConstructor
public class UserServiceImpl implements UserService {
    private final UserMapper userMapper;
    private final UserProfileMapper userProfileMapper;
    private final JwtUtils jwtUtils;
    private final PasswordEncoder passwordEncoder;

    private static final int DEFAULT_ROLE = 0; // 普通用户

    /**
     * 用户注册（含唯一性校验、密码加密、JWT生成）
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public LoginVO register(UserRegisterDTO userRegisterDTO) {
        // 1. 校验用户名唯一性
        LambdaQueryWrapper<User> usernameQuery = new LambdaQueryWrapper<>();
        usernameQuery.eq(User::getUsername, userRegisterDTO.getUsername());
        if (userMapper.selectOne(usernameQuery) != null) {
            throw new BusinessException(ResultCode.USERNAME_ALREADY_EXISTS);
        }

        // 2. 校验手机号唯一性
        if (userRegisterDTO.getPhone() != null) {
            LambdaQueryWrapper<User> phoneQuery = new LambdaQueryWrapper<>();
            phoneQuery.eq(User::getPhone, userRegisterDTO.getPhone());
            if (userMapper.selectOne(phoneQuery) != null) {
                throw new BusinessException(ResultCode.PHONE_ALREADY_EXISTS);
            }
        }

        // 3. 校验邮箱唯一性
        if (userRegisterDTO.getEmail() != null) {
            LambdaQueryWrapper<User> emailQuery = new LambdaQueryWrapper<>();
            emailQuery.eq(User::getEmail, userRegisterDTO.getEmail());
            if (userMapper.selectOne(emailQuery) != null) {
                throw new BusinessException(ResultCode.EMAIL_ALREADY_EXISTS);
            }
        }

        // 4. 密码加密
        String encryptedPassword = passwordEncoder.encode(userRegisterDTO.getPassword());

        // 5. 创建用户
        User user = User.builder()
                .username(userRegisterDTO.getUsername())
                .password(encryptedPassword)
                .phone(userRegisterDTO.getPhone())
                .email(userRegisterDTO.getEmail())
                .role(DEFAULT_ROLE).status(1).build();
        userMapper.insert(user);

        // 6. 创建用户档案
        UserProfile userProfile = UserProfile.builder()
                .userId(user.getId()).experienceLevel(0).build();
        userProfileMapper.insert(userProfile);

        // 7. 生成JWT Token
        String token = jwtUtils.generateToken(user.getId(), user.getUsername(), user.getRole());
        return LoginVO.builder().token(token).tokenType("Bearer")
                .userId(user.getId()).username(user.getUsername())
                .role(user.getRole()).status(user.getStatus()).build();
    }

    /**
     * 用户登录（含密码验证、JWT生成）
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public LoginVO login(UserLoginDTO userLoginDTO) {
        // 1. 查询用户
        LambdaQueryWrapper<User> queryWrapper = new LambdaQueryWrapper<>();
        queryWrapper.eq(User::getUsername, userLoginDTO.getUsername());
        User user = userMapper.selectOne(queryWrapper);

        // 2. 校验用户存在性和状态
        if (user == null) throw new BusinessException(ResultCode.USER_NOT_FOUND);
        if (user.getStatus() == 0) throw new BusinessException(ResultCode.USER_DISABLED);

        // 3. 验证密码
        if (!passwordEncoder.matches(userLoginDTO.getPassword(), user.getPassword())) {
            throw new BusinessException(ResultCode.PASSWORD_ERROR);
        }

        // 4. 更新登录时间并生成Token
        user.setLastLoginTime(LocalDateTime.now());
        userMapper.updateById(user);
        String token = jwtUtils.generateToken(user.getId(), user.getUsername(), user.getRole());

        log.info("用户登录成功，用户名：{}", user.getUsername());
        return LoginVO.builder().token(token).tokenType("Bearer")
                .userId(user.getId()).username(user.getUsername())
                .nickname(user.getNickname()).avatar(user.getAvatar())
                .role(user.getRole()).status(user.getStatus())
                .lastLoginTime(user.getLastLoginTime()).build();
    }
}
```

## 功能说明

- **用户注册**：校验用户名/手机号/邮箱唯一性，BCrypt密码加密，创建用户档案，生成JWT Token
- **用户登录**：验证用户名密码，校验账号状态，更新最后登录时间，生成JWT Token
- **安全机制**：密码使用BCrypt加密存储，JWT Token用于后续请求认证
