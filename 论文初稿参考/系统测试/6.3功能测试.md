# 6.3 功能测试

## 6.3.1 测试范围

本系统实现了户外徒步活动管理的完整业务流程，包括用户管理、活动管理、报名管理、签到与轨迹、路线管理、评价管理、系统管理等功能模块。本次系统测试覆盖了系统的核心业务功能，具体测试范围如表6-1所示。

表6-1 系统测试范围

| 序号 | 功能模块 | 功能概述 |
| :--- | :--- | :--- |
| 1 | 活动管理 | 管理徒步活动的全生命周期，包括创建、审核、发布、执行等环节 |
| 2 | 报名管理 | 管理用户对活动的报名申请，包括提交、审核、取消等操作 |
| 3 | 签到与轨迹 | 实现活动进行中的GPS签到验证和轨迹记录功能 |
| 4 | 路线管理 | 管理徒步路线信息，包括路线创建和路点配置 |
| 5 | 用户管理 | 管理用户账号和个人信息 |
| 6 | 评价管理 | 管理活动结束后的用户评价 |

## 6.3.4 测试执行

测试执行是将测试用例转化为实际操作的过程，通过执行测试用例验证系统功能是否符合预期。测试执行过程中，测试人员按照测试用例的步骤逐一操作，记录实际执行结果，并与期望结果进行对比。若实际结果与期望结果一致，则该测试用例通过；若不一致，则记录缺陷并反馈给开发人员修复。

本系统测试执行采用手工测试方式，测试人员使用Chrome浏览器访问系统，按照测试用例逐步执行操作。测试执行结果汇总如表6-6所示。
