**全局类图实体说明（共15个）**：

| 序号 | 实体类 | 中文名称 | 主要属性 | 说明 |
|:---:|:---|:---|:---|:---|
| 1 | User | 用户 | id、nickname、role | 系统核心参与者，角色分为用户(0)、组织者(1)、管理员(2) |
| 2 | UserProfile | 用户资料 | id、userId、realName、gender、phone | 用户详细信息，与User是1对1关系 |
| 3 | Activity | 活动 | id、title、organizerId、routeId、status、maxParticipants | 徒步活动实体，支持7种状态流转 |
| 4 | Route | 路线 | id、name、distance、difficulty | 徒步路线信息，可被多个活动复用 |
| 5 | RoutePoint | 路点 | id、routeId、latitude、longitude、pointType | 路线上的节点，包含起点、终点、途经点等类型 |
| 6 | Checkpoint | 检查点 | id、activityId、name、latitude、longitude、radius | 活动签到验证点，包含有效半径 |
| 7 | Registration | 报名记录 | id、userId、activityId、status、queueNumber | 用户报名申请，支持6种状态 |
| 8 | CheckInRecord | 签到记录 | id、userId、checkpointId、checkInTime、status | GPS签到验证记录 |
| 9 | TrackRecord | 轨迹记录 | id、userId、activityId、latitude、longitude、recordTime | 用户行进轨迹数据 |
| 10 | AlertEvent | 预警事件 | id、userId、activityId、alertType、alertLevel、status | 轨迹异常预警，包含偏离、超时、失联等类型 |
| 11 | GatheringPlan | 集合方案 | id、activityId、gatheringTime、gatheringPlace | 活动集合信息，与Activity是1对1关系 |
| 12 | Review | 评价 | id、userId、activityId、overallRating、content | 活动结束后的用户评价 |
| 13 | Message | 消息 | id、userId、title、content、isRead | 站内消息通知 |
| 14 | DictType | 字典类型 | id、dictType、dictName、status | 系统字典分类 |
| 15 | DictData | 字典数据 | id、dictTypeId、dictValue、dictLabel | 字典具体数据项 |

**类关系说明**：

| 关系 | 多重性 | 说明 |
|:---|:---|:---|
| User → UserProfile | 1 对 1 | 一个用户对应一份详细资料 |
| User → Activity | 1 对 * | 一个组织者创建多个活动 |
| User → Registration | 1 对 * | 一个用户提交多个报名 |
| User → CheckInRecord | 1 对 * | 一个用户产生多条签到记录 |
| User → TrackRecord | 1 对 * | 一个用户上报多条轨迹数据 |
| User → Review | 1 对 * | 一个用户发表多个评价 |
| User → Message | 1 对 * | 一个用户接收多条消息 |
| User → AlertEvent | 1 对 * | 一个用户触发多个预警 |
| Activity → Route | * 对 1 | 多个活动使用同一条路线 |
| Activity → Checkpoint | 1 对 * | 一个活动包含多个检查点 |
| Activity → Registration | 1 对 * | 一个活动有多个报名记录 |
| Activity → GatheringPlan | 1 对 1 | 一个活动对应一个集合方案 |
| Route → RoutePoint | 1 对 * | 一条路线包含多个路点 |
| Checkpoint → CheckInRecord | 1 对 * | 一个检查点产生多条签到记录 |
| DictType → DictData | 1 对 * | 一个字典类型包含多个字典数据 |

该全局类图从系统整体视角展示了所有15个核心实体及其关联关系，为后续的数据库设计、接口设计和功能实现提供了全局性的依据。
