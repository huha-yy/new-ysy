# 4.5.2 界面设计

本系统界面设计遵循简洁、直观、易用的原则，采用现代化扁平设计风格，注重用户体验和交互效率。以下从设计规范和界面展示两个方面进行说明。

## ① 设计规范

此规范为户外徒步活动管理系统基础规范，未涉及内容采用相似性原则进行设计。

### 1）色彩规范

系统主色调采用绿色系，寓意户外、自然、健康，与徒步活动主题相呼应。

| 色彩类型 | 色值 | 用途 |
| :--- | :--- | :--- |
| 主色 | #52c41a（绿色） | 主按钮、成功状态、已完成标签 |
| 辅助色 | #1890ff（蓝色） | 链接、进行中状态、信息提示 |
| 警告色 | #fa8c16（橙色） | 待审核状态、中等难度标签 |
| 危险色 | #ff4d4f（红色） | 错误提示、已取消状态、困难难度标签 |
| 背景色 | #f5f5f5（浅灰） | 页面背景、卡片背景 |
| 文字色 | #333333（深灰） | 标题文字 |
| 次要文字 | #666666（中灰） | 正文文字 |
| 辅助文字 | #999999（浅灰） | 说明文字、时间戳 |

难度等级采用差异化配色：休闲（绿色）、简单（蓝色）、中等（橙色）、困难（红色）、极限（紫色），便于用户快速识别活动强度。

### 2）字体规范

系统采用系统默认字体栈，确保跨平台显示一致性。

| 字体类型 | 字体族 | 字号 | 行高 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| 标题字体 | -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto | 24px / 20px / 18px | 1.4 | 页面标题、卡片标题 |
| 正文字体 | 'PingFang SC', 'Microsoft YaHei', sans-serif | 14px | 1.6 | 正文内容、表单标签 |
| 辅助字体 | 'Helvetica Neue', Arial | 12px | 1.5 | 说明文字、标签 |
| 数字字体 | 'DIN Alternate', 'Roboto Mono' | — | — | 金额、统计数字 |

### 3）图标设计规范

系统图标采用 Ant Design Icons 图标库，保持风格统一。

| 图标类型 | 尺寸 | 线条粗细 | 用途 |
| :--- | :--- | :--- | :--- |
| 导航图标 | 20px | 1.5px | 顶部导航、侧边菜单 |
| 操作图标 | 16px | 1.5px | 按钮图标、列表操作 |
| 状态图标 | 14px | 1px | 状态标签、提示信息 |
| 大图标 | 48px | 2px | 空状态、加载状态 |

常用图标语义：日历（活动日期）、位置（地点/路线）、用户（组织者/参与者）、团队（人数）、星星（评价/收藏）、警告（预警/注意）。

### 4）间距规范

系统采用8px基础间距单位，所有间距为8的倍数，保证视觉节奏一致。

| 间距类型 | 数值 | 用途 |
| :--- | :--- | :--- |
| 最小间距 | 8px | 图标与文字间距、内边距 |
| 小间距 | 16px | 卡片内边距、表单项间距 |
| 中间距 | 24px | 区块间距、模块间距 |
| 大间距 | 32px | 页面边距、大区块间距 |

### 5）圆角规范

| 元素类型 | 圆角大小 | 示例 |
| :--- | :--- | :--- |
| 按钮 | 6px | 主要按钮、次要按钮 |
| 卡片 | 8px | 活动卡片、信息卡片 |
| 输入框 | 6px | 文本输入、下拉选择 |
| 标签 | 4px | 状态标签、难度标签 |
| 弹窗 | 8px | 对话框、抽屉 |

### 6）交互反馈规范

| 交互类型 | 反馈方式 | 示例 |
| :--- | :--- | :--- |
| 按钮点击 | 颜色加深 + 按下效果 | 主按钮点击时颜色加深10% |
| 卡片悬停 | 阴影增强 + 轻微上浮 | 活动卡片悬停时上浮2px |
| 加载状态 | Loading动画 + 禁用操作 | 数据加载时显示旋转图标 |
| 操作成功 | 成功提示 + 自动消失 | 报名成功显示绿色提示3秒 |
| 操作失败 | 错误提示 + 原地停留 | 表单校验失败显示红色提示 |

## ② 部分UI界面展示

### 1）首页界面

首页是用户进入系统后的第一个页面，主要展示平台核心内容。界面顶部为导航栏，包含Logo、导航菜单和用户操作区；主体区域展示轮播图、热门活动推荐和热门路线推荐。页面整体采用白色背景搭配浅灰色区块，视觉层次分明。

### 2）活动列表页界面

活动列表页采用卡片式布局，每个活动卡片包含封面图、标题、路线信息、日期、难度标签和报名人数。卡片采用圆角设计，悬停时显示阴影效果。难度标签通过颜色区分，便于用户快速筛选。页面底部为分页组件，支持翻页浏览。

### 3）活动详情页界面

活动详情页采用纵向滚动布局，从上到下依次展示：封面大图、标题标签区、基本信息区、组织者卡片、路线信息卡片、装备要求、体能要求、Tab内容区（评价/集合信息）。底部固定操作栏，包含集合信息、评价和报名按钮，方便用户随时操作。

### 4）签到页面界面

签到页面采用地图与列表结合的双栏布局。左侧地图区域显示签到点标记和用户当前位置；右侧列表区域展示签到进度和签到点详情，每个签到点项包含序号、名称、距离和签到按钮。签到按钮根据距离动态显示状态，已完成签到显示绿色标签和时间。

### 5）报名弹窗界面

报名弹窗采用居中对话框形式，包含活动简要信息、报名表单和报名须知三个区域。表单采用垂直布局，必填项标注红色星号。底部为取消和确认按钮，确认按钮采用主色调突出显示。
